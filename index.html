可复用 Prompts

1. 创建作品集页面
给 1vk3y.github.io 做一个单页作品集，展示后端工程项目。页面要简洁专业，适合招聘方快速浏览。包含：项目截图、技术栈、简要说明。移动端优先，响应式布局。
2. 添加固定导航
将各小节的标题做成磁吸样式（模仿时间线），方便在页面任何地方都可以点到其他小节（包括顶部、底部）。桌面端右侧垂直导航，移动端底部水平导航，自动高亮当前区块。
3. 嵌入外部播放器
嵌入网易云音乐外链播放器，处理跨域错误和 alert 弹窗，添加加载超时重试机制，确保播放器稳定显示。拦截"资源加载失败"弹窗，console 错误来自第三方脚本无法消除但不影响功能。
4. 响应式卡片布局
卡片改成左图右文布局：≥1024px 时截图在左（40%宽度），文字在右；<1024px 时上图下文，截图居中最大 260px。去掉截图底板，确保两张卡片截图尺寸一致。
5. 图片压缩和处理
将截图复制到 assets/，宽度缩到 1600px 以内，转成 jpg，每张不超过 300KB。不裁切画面，不加滤镜。使用 sips -Z 1600 和 formatOptions 85。
6. 验收测试
验收：375、768、1280 三种宽度下 scrollWidth 等于 clientWidth（375 宽放进 iframe 里测，加 --allow-file-access-from-files）。只 add 指定文件，提交推送，贴 git show --stat HEAD。
